Задача: перевести калибровку порога и сравнение методов скоринга аномалий на критерий Неймана-Пирсона. Сначала прочитай код и ответь на вопросы из блока «Сначала проверь», ничего не меняя. Правки вноси только после моего подтверждения.

Контекст
Для каждого метода скоринга m задана статистика окна s_m(w): NLL + квантиль по окну, top-k + квантиль, длина серии аномальных шагов. Решающее правило: окно аномально, если s_m(w) > τ_m.

Требуемая логика
1. Уровень ложных срабатываний α задаётся заранее и не подбирается по размеченным атакам. По умолчанию α = 1% (то есть процентиль 99,0), в конфиге это отдельный параметр.
2. Порог τ_m для каждого метода вычисляется только по нормальным валидационным окнам как (1−α)-квантиль распределения s_m(w). Размеченные атаки при выборе τ_m не используются.
3. Сравнение методов идёт при одинаковом α: по тестовой выборке считаются recall, precision, F1 при этом α и ROC-AUC. F1 выступает только метрикой, не критерием выбора порога.
4. Гиперпараметры статистики (q для квантиля окна, k для top-k, шаговый процентиль для длины серии, способ агрегации) выбираются на отдельной размеченной выборке по максимуму recall при фиксированном α (критерий Неймана-Пирсона). Для каждого кандидата порог τ предварительно перекалибруется по нормальной валидации под тот же α. F1 в выборе параметров не участвует: он считается только на итоговой тестовой выборке как метрика качества.
5. Результаты выводятся таблицей: строки это методы, столбцы это recall и precision при α = 0,1%, 1%, 5%, плюс ROC-AUC.
